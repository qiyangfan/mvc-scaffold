# ADR-0005: 自动化质量门禁基线决策

## 状态

已接受 (Accepted) — 2026-10

## 上下文 (Context)

随着团队规模扩大和 AI 编码工具的大规模使用，缺乏自动化硬约束的代码库极易出现代码格式各异、低级空指针缺陷隐匿、架构分层退化、测试覆盖率虚标等问题。
口头规范或人工 Code Review 难以稳定阻断所有不合规代码。

## 决策 (Decision)

在构建生命周期的 `verify` 阶段，固化 5 个不可跳过的硬性质量门禁：

1. **Spotless (2.44.3)**：执行统一代码缩进与排版，支持 `mvn spotless:apply` 一键自动格式化；
2. **PMD (3.26.0)**：排查潜在设计缺陷、并发陷阱与空指针问题，违规即阻断构建；
3. **SpotBugs (4.8.6.6)**：深入字节码扫描不可见缺陷；
4. **JaCoCo (0.8.12)**：统计单元测试代码覆盖，设置指令覆盖率 ≥ 70%、分支覆盖率 ≥ 50% 的硬性下限；
5. **ArchUnit (1.5.0)**：以 JUnit 5 测试形式执行四层架构调用方向、DO 不得泄露至 Controller 断言。

## 后果 (Consequences)

### 正向收益

- CI 构建成为绝对权威的质量裁判，不合规代码 100% 无法合入主干；
- 开发者在本地即可得到与 CI 完全一致的质量反馈。
